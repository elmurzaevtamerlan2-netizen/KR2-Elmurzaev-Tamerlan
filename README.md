# КР2 — практические работы 4, 5 и 6

**Студент:** Эльмурзаев Тамерлан Заурович  
**Группа:** ЭПБО-02-25

В репозитории размещены три PHP-проекта:

- `pr04` — обработка HTML-форм, серверная проверка данных, чтение CSV и фильтрация списка сотрудников.
- `pr05` — объектно-ориентированная модель каталога товаров и сервис чтения JSON.
- `pr06` — хранение заметок в JSON, PHP-сессии и разделение обработчика с HTML-шаблоном.

В каждой папке находится собственный `README.md` с инструкцией запуска. Требуется PHP 8.1 или новее.

## Запуск

- Практическая 4: `cd pr04 && php -S localhost:8004 -t public` → http://localhost:8004
- Практическая 5: `cd pr05 && php -S localhost:8005 -t public` → http://localhost:8005
- Практическая 6: `cd pr06 && php -S localhost:8006 -t public` → http://localhost:8006

## Исходные данные

В папках `pr04/dataset`, `pr05/dataset` и `pr06/dataset` размещены пояснения о необходимых файлах. Оригинальные наборы данных из комплекта преподавателя не были приложены к доступным материалам, поэтому их нужно добавить перед окончательной проверкой. Не заменяйте их произвольными данными.
