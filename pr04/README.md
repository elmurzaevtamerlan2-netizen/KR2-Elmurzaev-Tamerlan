Приложение читает `dataset/employees.csv`, отображает сотрудников, обрабатывает форму POST, проверяет поля и фильтрует список через GET. Пользовательские значения перед выводом экранируются через `htmlspecialchars`.

## Запуск
Из папки `pr04`: `php -S localhost:8004 -t public`, затем открыть `http://localhost:8004`.

## Проверка
Проверить пустое имя, неверный email, длину строк, границы числового поля и фильтр отдела. Контрольные сценарии берутся из `dataset/form_cases.json`.

Оригинальные файлы `employees.csv` и `form_cases.json` нужно поместить в `dataset/`: они не входили в переданные материалы задания.
