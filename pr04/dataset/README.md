# Исходные данные практической работы №4

В эту папку необходимо поместить оригинальные `employees.csv` и `form_cases.json` из комплекта преподавателя. Они не были приложены к доступным в чате материалам. Приложение читает эти файлы напрямую; заменять их самостоятельно составленными данными без согласования с преподавателем не следует.
