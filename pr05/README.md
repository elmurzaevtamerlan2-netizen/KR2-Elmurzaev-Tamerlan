Каталог использует модели `Product` и `Category`, а `CatalogService` читает JSON-файлы и создаёт объекты. HTML-вывод отделён от моделей.

## Запуск
Из папки `pr05`: `php -S localhost:8005 -t public`, затем открыть `http://localhost:8005`.

В `dataset` должны находиться оригинальные `products.json`, `categories.json` и `class_requirements.csv` из комплекта преподавателя. Эти файлы не были приложены к доступным материалам, поэтому их содержимое здесь не подменено тестовыми данными.
