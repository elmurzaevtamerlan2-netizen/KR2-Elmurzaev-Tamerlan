Каталог использует модели `Product` и `Category`, а `CatalogService` читает JSON-файлы и создаёт объекты. HTML-вывод отделён от моделей.

## Запуск
Из папки `pr05`: `php -S localhost:8005 -t public`, затем открыть `http://localhost:8005`.

## Набор данных

Каталог загружается из `dataset/products.json` и `dataset/categories.json`. Файл `class_requirements.csv` содержит таблицу используемых классов и их назначения. Наборы данных подготовлены для демонстрации структуры, описанной в задании, и не являются оригинальными файлами из архива преподавателя.
