# Исходные данные практической работы №5

В эту папку необходимо поместить оригинальные `products.json`, `categories.json` и `class_requirements.csv` из комплекта преподавателя. Эти файлы не были приложены к доступным в чате материалам. `CatalogService` читает первые два JSON-файла, а CSV используется для сверки состава свойств моделей.
