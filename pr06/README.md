# Практическая работа №6 — JSON и сессии

**Студент:** Эльмурзаев Тамерлан Заурович

Приложение читает и сохраняет заметки в JSON, использует PHP-сессию для хранения имени пользователя и передаёт подготовленные данные в шаблон `templates/list.php`.

## Запуск
Из папки `pr06`: `php -S localhost:8006 -t public`, затем открыть `http://localhost:8006`. PHP должен иметь право записи в `dataset/notes.json`.

В `dataset` нужно положить оригинальные `notes.json`, `users.json` и `session_scenarios.json` из комплекта преподавателя. Эти исходные файлы не были приложены к доступным материалам.
