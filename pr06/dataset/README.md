# Исходные данные практической работы №6

В эту папку необходимо поместить оригинальные `notes.json`, `users.json` и `session_scenarios.json` из комплекта преподавателя. Эти файлы не были приложены к доступным в чате материалам. Приложение использует JSON для хранения заметок и списка пользователей, сценарии предназначены для ручной проверки сессий.
